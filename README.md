# Career Compass: From Confusion to Career Clarity

Career Compass is a web-based application designed to help engineering students explore technology career paths based on their interests and preferences. The platform guides students from career discovery to specialization and provides learning roadmaps and curated resources to begin their journey.

# Problem Statement

Many engineering students are aware of only a few popular technology careers and often struggle to identify the domain that best matches their interests and strengths. As a result, they find it difficult to decide what skills to learn and how to begin their career journey.

# Objectives

- Help students discover suitable technology domains.
- Recommend career specializations based on user interests.
- Provide detailed career information.
- Offer structured learning roadmaps.
- Share curated learning resources for beginners.

# How It Works

1. Open the application.
2. Complete the Career Discovery Assessment.
3. Receive a recommended technology domain.
4. Take the Specialization Assessment.
5. Explore career details and required skills.
6. Follow the learning roadmap.
7. Access curated learning resources.

# Installation

1. Clone the repository

git clone https://github.com/your-username/career-compass.git


2. Navigate to the project folder

cd career-compass

3. Install the required packages

pip install -r requirements.txt

4. Run the Flask application

python main.py

5. Open your browser and visit

http://127.0.0.1:5000/
